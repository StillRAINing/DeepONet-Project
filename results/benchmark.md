## Break-even: how many queries until the surrogate pays for itself

Cost to build the surrogate = data generation (estimated 2924 s = 292.4 ms x 10,000 scalar RK4 trajectories, serial) + training (`train_seconds` from the checkpoint; measured while other runs shared the CPU for some models, so treat as an upper bound). N* = (data + training) / (solver time per query - surrogate time per query), batch-64 surrogate time. The matched `solve_ivp` is the tolerance whose median error is closest to the surrogate's; that is the fair comparison (weak point 3); its error is shown so you can see how close the match is.
