src.data

Seeded dataset generation: sample parameters and torque profiles, simulate, split train/val/test.

Each sample is one trajectory of the arm:

params (2,) [m_p, b] torque (2, N_T) tau_j(t_i) = A_j sin(2 pi f_j t_i + phi_j) on the fixed grid traj (N_T, 4) x(t_i) = [q1, q2, q1dot, q2dot], from RK4

Ground truth is RK4 with substeps internal steps per output interval. Besides the train/val/test split (in-range) there is an out-of-range set with heavier payload and higher friction, used only for extrapolation tests.

Run python -m src.data to write data/dataset.npz (sine torque family). Run python -m src.data --smooth to write data/dataset_smooth.npz (smooth random torque family, the main experiment: see the section below generate and docs/DESIGN_LOG.md).
