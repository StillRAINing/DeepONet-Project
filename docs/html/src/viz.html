src.viz

Interactive pygame viewer for the 2-link arm.

Run with python -m src.viz from the repo root.

Shows the RK4 ground truth (the same simulate used to build the dataset) for any payload / friction / torque setting, with live re-solving as sliders move. Slider tracks shade the in-range domain; going past it is out-of-range territory.

Keys:

SPACE pause/play R restart [ / ] slower / faster G toggle the passive ghost arm (tau = 0, i.e. a pure double pendulum) K toggle RK45 reference overlay (adaptive solver, should sit on RK4) N load a random test sample from data/dataset.npz (O: out-of-range sample) D reset sliders to defaults P save a screenshot to results/

Click or drag on any time-series plot to scrub.

Surrogates (DeepONet / MLP) plug in through SURROGATES: a name -> callable f(params, coef) -> traj (N_T, 4) mapping. They are drawn as extra arms and traces once registered.

class App:

Interactive pygame window: sliders for the inputs, the arm animation, joint plots and energy.

The RK4 ground truth is always shown; RK45 and any registered surrogates are overlaid. Keys: space pause, [ ] speed, R restart, G passive ghost, K RK45 overlay, N / O random test / out-of-range sample, D defaults, P screenshot.

def inputs(self):

Current slider values as (params (2,), coef (2, 3)) = [m_p, b] and [A, f, phi] per joint.

def set_inputs(self, params, coef):

Move the sliders to params and coef (clipped to each slider's range).

def solve(self):

Re-run RK4 (and the passive and surrogate overlays) for the current slider values.

def solve_rk45(self):

Integrate the current inputs with the adaptive RK45 solver for the overlay.

def state_at(self, traj):

Linear interpolation of a (N_T, 4) trajectory at the current animation time self.t.

def load_sample(self, split):

Set the sliders to a random sample of split from the dataset (no-op if no dataset file).

def handle(self, ev):

Process one pygame event: slider drags, time scrubbing and the key bindings.

def draw_arm_panel(self):

Draw the arm animation panel with tip trails, legend and the status text.

def in_range(self):

True if every slider is inside its training range (bright part of the track).

def arm_sets(self):

List of (name, trajectory, colour) to draw: RK4, optional RK45, then each surrogate.

def draw_panels(self):

Draw the sliders and the angle, velocity and energy plots.

def run(self, max_frames=None, screenshot=None):

Main loop. max_frames stops after that many frames; screenshot saves the last frame to that path.
